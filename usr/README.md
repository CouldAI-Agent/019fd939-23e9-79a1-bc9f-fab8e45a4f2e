# Calculadora de Rescisão Contratual

Um aplicativo multiplataforma (iOS, Android, Web, Desktop) construído em Flutter para calcular rescisões contratuais de trabalho, com suporte a cálculo de comissões, médias de comissão, 13º salário, férias proporcionais, FGTS e multa de 40%.

## Funcionalidades

- **Cálculo de Verbas Rescisórias**: Calcula saldo de salário, aviso prévio, 13º proporcional, férias proporcionais e 1/3 de férias.
- **Integração de Comissões**: Calcula a média das comissões e integra nos cálculos de DSR, 13º e férias.
- **Cálculo de FGTS e Multa**: Calcula o FGTS sobre as verbas devidas e a multa de 40% (ou 20% dependendo do tipo de rescisão).
- **Justificativas de Cálculo**: Exibe um resumo de como cada rubrica foi calculada.

## Como Executar

1. Certifique-se de ter o Flutter instalado.
2. Clone o repositório.
3. Execute `flutter pub get` para instalar as dependências.
4. Execute `flutter run` para iniciar o aplicativo.
